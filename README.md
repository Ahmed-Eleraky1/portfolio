# Ahmed Eleraky — Portfolio

Personal portfolio of Ahmed Eleraky, Software Sales Specialist for web and mobile solutions.

**Live site:** https://ahmed-eleraky.vercel.app

## About

A single-page, responsive site covering my sales process, experience, the sales documents I prepare, skills, education and the E-Vital project.

## Built with

- HTML5 and CSS3 (no framework, no build step)
- Google Fonts: Sofia Sans Condensed and Instrument Sans
- Light and dark mode, mobile-first layout
- Deployed on Vercel

## Run locally

Open `index.html` in any browser.
