# Ahmed Eleraky — Portfolio

Personal portfolio of Ahmed Eleraky, Software Sales Specialist for web and mobile solutions.

**Live site:** https://ahmed-eleraky.vercel.app

![Portfolio preview](https://img.shields.io/badge/status-live-d7ff3c?style=flat)

## What's inside

- **3D hero:** my portrait at the centre with my skills and tools orbiting around it in 3D. Hover a skill to highlight it, move the mouse to tilt the scene, or drag to spin the orbit.
- **SAR 200,000+ in closed software sales**, with an animated counter.
- **How I sell:** a pinned section that scrolls sideways through my five-step sales process.
- **Deal story:** a car auction app closed in 14 days, with a pinned day counter that fills as you read.
- **B2B and B2C**, experience timeline, skills, education and contact.

## Built with

- HTML, CSS and vanilla JavaScript (single file, no build step)
- [Three.js](https://threejs.org/) r128 for the 3D orbit scene
- [GSAP](https://gsap.com/) 3.12 with ScrollTrigger for scroll animations and pinned sections
- Google Fonts: Archivo (expanded) and Inter
- Responsive down to mobile, with a non-WebGL fallback and reduced-motion support
- Deployed on [Vercel](https://vercel.com/)

## Run locally

Clone the repo and open `index.html` in a browser. A local server (for example `npx serve`) is recommended so the photo loads as a WebGL texture.
